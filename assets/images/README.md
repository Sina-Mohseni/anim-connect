# Guide d'intégration des images

Pour finaliser le design du site **Hourglass Gate**, veuillez placer les images fournies dans ce dossier avec les noms suivants:

## Images requises:

1. **hourglass.jpg** - L'image de l'hourglass futuriste avec fond bleu cyan
   - Utilisée comme élément principal dans la section hero
   - Dimensions recommandées: 600x800px

2. **tech-cube.jpg** - L'image du cube technologique blanc
   - Utilisée pour la carte "Nexus Technologique"
   - Dimensions recommandées: 700x500px

3. **dragon-seal.jpg** - Le médaillon avec le dragon en flammes
   - Utilisée pour la carte "Sceau du Dragon"
   - Dimensions recommandées: 700x500px

4. **arcane-card.jpg** - La carte mystique avec le "A" doré
   - Utilisée pour la carte "Porte Arcanique"
   - Dimensions recommandées: 700x500px

5. **camera-log.jpg** (optionnel) - L'interface camera log
   - Peut être utilisée comme texture de fond
   - Dimensions recommandées: 1920x1080px

## Instructions:

1. Sauvegardez les images que vous m'avez envoyées
2. Renommez-les selon la liste ci-dessus
3. Placez-les dans le dossier `/assets/images/`
4. Le site les chargera automatiquement

## Alternative - Images de placeholder:

Si vous souhaitez tester le site sans les images, le design fonctionnera avec des couleurs de fond dégradées qui s'afficheront à la place.
