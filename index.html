CONCEPT

⧖

Le Hourglass Project

Un univers commun reliant toutes les époques de l'humanité. Chaque aventure est une mission temporelle où les joueurs incarnent des agents du projet Hourglass, explorant différentes périodes historiques.

◈

Structure des Aventures

Mondes → Différentes lignes temporelles
Époques → Périodes historiques (Préhistoire, Antiquité, etc.)
Sagas → Séries d'aventures connectées
Projets → Aventures IRL individuelles

⬢

Règles de Base

Toutes les aventures partagent un système de jeu commun avec des règles de base universelles. Chaque projet ajoute ensuite ses propres mécaniques spécifiques pour créer des expériences uniques.

✦

Personnalisation

Choisissez la difficulté (Facile/Normal/Difficile), le mode de jeu (Coop/Compétitif/Semi), et la zone de jeu (Table/Pièce/Multi-pièces).
